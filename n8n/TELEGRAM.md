# Telegram student-agenda bot

Workflow: `n8n/workflows/study-planner-telegram.json` (generated by `n8n/workflows/build_workflow.py` from `prompts/planner-telegram-v1.md`).

```
Telegram Trigger -> AI Agent -> Send reply (Telegram)
   Agent sub-nodes: Gemini model | Simple Memory (per chat id) | Campus READ (5 read tools)
                    Human review (Telegram)  <-  Campus WRITE (3 write tools)
```
Every write tool call makes the bot send you a Telegram message with **✅ Aprobar / ❌ Rechazar** buttons showing the tool name and parameters. Only after Approve does the write run; on Decline the agent is told not to retry and proposes an alternative.

## Setup (≈10 min)
1. **Bot**: in Telegram open `@BotFather` → `/newbot` → copy the token (secret: never commit it).
2. **Public URL** (required: Telegram only calls HTTPS webhooks, and the approval buttons are links your phone must open). Start a tunnel to n8n, e.g. `cloudflared tunnel --url http://localhost:5678` or `ngrok http 5678`. Put the https URL in `.env` as `WEBHOOK_URL=https://xxxx.trycloudflare.com/` (trailing slash), then `make up`.
3. **n8n**: open the n8n **public URL** (so editor and webhooks agree). Create credentials: **Telegram API** named `Telegram Bot` (token) and **Google Gemini(PaLM) API** named `Gemini` (key).
4. **Import**: Workflows → ⋯ → *Import from file* → the JSON. Open each node with a red credential warning (Telegram Trigger, Human review, Send reply, Gemini) and select the credential. Open *Campus READ / WRITE* and check the tool lists load (endpoint `http://campus-mcp:8000/mcp`).
5. **Restrict the bot** (it is public on Telegram): message `@userinfobot` for your numeric id, then in *Telegram Trigger → Additional Fields → Restrict to User IDs* add it.
6. **Activate** the workflow (toggle top-right). The Telegram trigger only receives messages while the workflow is active; one trigger per bot.
7. `make reset`, then chat with your bot: paste the messages from `demo/messages.md`.

## Troubleshooting
| Symptom | Fix |
|---|---|
| Activating fails: "bad webhook: An HTTPS URL must be provided" | `WEBHOOK_URL` is not a public https URL, or n8n was not restarted after changing it (`make up`). |
| Bot never answers | Workflow not active; or user-id restriction excludes you; check *Executions*. |
| Approval buttons open an unreachable page | Phone cannot reach `WEBHOOK_URL` (tunnel down / URL changed). |
| Writes run without approval | Campus READ includes a write tool, or Campus WRITE is wired to the agent directly instead of through *Human review*. |
| Reply fails with a Telegram parse error | Do not set a parse mode on *Send reply*; the prompt asks for plain text. |
| MCP errors | See *Troubleshooting* in `BUILD.md` (use `campus-mcp`, path `/mcp`, HTTP Streamable). |
